# Document Templates

Structure to follow for each supported document type. These are conventions expected by native readers, not stylistic suggestions.

## 1. Official / Business Letter (خطاب رسمي)

```
[مكان وتاريخ الإرسال]                              (place and date, top right for MSA)

[اسم/صفة المرسل إليه]
[الجهة/المؤسسة]
[العنوان إن وجد]

الموضوع: [subject line — one line, no verb-first phrasing]

السادة/السيد/السيدة [اسم] المحترم/المحترمة،
تحية طيبة وبعد،  (or السلام عليكم ورحمة الله وبركاته، تحية طيبة وبعد، if opening with Islamic greeting is contextually appropriate)

[Body — 2-4 paragraphs: reason for writing, context/details, the specific request or informational point, closing courtesy line]

وتفضلوا بقبول فائق الاحترام والتقدير،

[الاسم]
[الصفة/المنصب]
[معلومات الاتصال]
```

Rules:
- Subject line (الموضوع) is mandatory for administrative letters — never skip it.
- Never open a formal letter with the person's first name alone; always title + surname or title + full name.
- The closing courtesy line varies by hierarchy — see `regional-conventions.md` and `tone-tiers.md`.

## 2. Administrative Correspondence (مراسلة إدارية) — requests, complaints, follow-ups

Same skeleton as the official letter, but body follows a stricter three-part structure:
1. **الإشارة** (reference) — what this concerns, dated/numbered if replying to something
2. **العرض** (the matter itself) — factual, unemotional even for complaints; state facts before requesting action
3. **الطلب** (the specific ask) — one clear, unambiguous request at the end

Avoid emotional language even in complaint letters — formal Arabic administrative register stays factual; the force comes from precision, not intensity.

## 3. CV / Resume (السيرة الذاتية)

```
الاسم الكامل
معلومات الاتصال (هاتف، بريد إلكتروني، المدينة)

الهدف المهني (اختياري، سطر أو سطرين فقط — لا فقرة كاملة)

المؤهلات العلمية
  [الشهادة] — [المؤسسة] — [السنة]

الخبرة المهنية
  [المسمى الوظيفي] — [الجهة] — [الفترة]
  • [مهمة/إنجاز بصيغة الفعل الماضي، مختصر]

المهارات
  [قائمة موجزة، لا فقرات]

اللغات
  [اللغة — المستوى]
```

Rules:
- Bullet points for experience, not paragraphs. This is one of the most common mistakes when a CV is drafted by translating a Western-style narrative CV directly — Arabic professional CVs (like most modern CVs generally) favor scannable bullets.
- Use consistent verb tense (الماضي) for past roles throughout — don't mix.
- No photo placeholder text, no marital status/religion/age fields unless the user explicitly says the target employer/country requires them (some Gulf-region employers still request this; it is not standard and should never be added by default).

### Regional CV variants

The skeleton above is the safe neutral default. Two real regional differences worth knowing:

- **Gulf-region CVs**: personal-info fields (nationality, marital status, date of birth, sometimes a photo) are still commonly requested by employers in some Gulf countries, more often than in the Maghreb, Egypt, or Levant. Still never add these by default — only include them if the user says the job posting/employer asks for them, and place them in a short header block, not woven into the professional sections.
- **Maghreb-region CVs** (Algeria, Morocco, Tunisia): French-influenced dual-column or "compétences" (المهارات) sections are common in bilingual/francophone-adjacent job markets, and academic/technical titles (مهندس، دكتور) before the name are used more consistently than in Gulf/Levant CVs. If the user is applying to a francophone-influenced employer, ask whether they want a bilingual Arabic/French CV rather than Arabic-only — this skill drafts the Arabic side; a French-side CV is outside its scope unless the user pastes existing French content to adapt.

## 4. Cover Letter (خطاب تقديم / رسالة تحفيزية)

Three-paragraph structure:
1. Why this role/institution specifically (not generic)
2. Concrete evidence of fit — one or two specific examples, not a restated CV
3. Closing — availability, thanks, call to action

Keep it under one page equivalent. Formal but warmer register than an administrative letter — closing formula is less rigid (see `tone-tiers.md`, Tier 2).

## 5. Report (تقرير)

```
عنوان التقرير

المقدمة (context, purpose, scope — short)

المحاور / العناصر الأساسية
  [numbered or titled sections, each with its own short intro]

النتائج / الخلاصة

التوصيات (if applicable)
```

Rules:
- Section headers are mandatory for anything over ~1 page — don't submit a wall of text.
- Use numbered lists for sequential items, bullet points for non-sequential ones — don't mix arbitrarily.
- Passive constructions (تم إنجاز... / تم تحقيق...) are standard and expected in formal reports — this is one place where what would be "weak passive voice" in English is the correct register in Arabic.

## 6. Memo / Internal Note (مذكرة داخلية)

```
مذكرة داخلية
إلى: [recipient/department]
من: [sender/department]
التاريخ: [date]
الموضوع: [subject]

[body — shorter and more direct than an external letter; internal hierarchy still respected but courtesy formulas are lighter]
```

## 7. Meeting Minutes (محضر اجتماع)

```
محضر اجتماع
التاريخ: / المكان: / الحاضرون: / الغائبون (إن وجد):

جدول الأعمال:
  1. ...
  2. ...

المداولات (مختصرة، بصيغة الماضي، بدون آراء شخصية للمحرر)

القرارات المتخذة:
  • ...

المهام الموكلة:
  [المهمة — المسؤول — الأجل]
```

Rules:
- Minutes are written in third person, past tense, no editorializing by the note-taker.
- Decisions and action items must be visually separated from the discussion narrative — never buried in prose.

## 8. Simple Contract / Agreement (عقد/اتفاقية بسيطة)

**This skill drafts simple, low-stakes agreements only** (e.g. freelance work agreements, simple MOUs) — always include a note that the user should have any contract with legal weight reviewed by a licensed lawyer in their jurisdiction before signing. Never present a drafted contract as legally vetted.

```
عقد/اتفاقية [نوعها]
المبرم بين:
الطرف الأول: [...]
الطرف الثاني: [...]

المادة 1: الموضوع
المادة 2: الالتزامات
المادة 3: المدة
المادة 4: المقابل المالي (إن وجد)
المادة 5: فسخ الاتفاقية
المادة 6: أحكام ختامية

حرر بتاريخ: ... في نسختين، لكل طرف نسخة.

الطرف الأول: التوقيع              الطرف الثاني: التوقيع
```
