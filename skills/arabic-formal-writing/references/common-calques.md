# Common Calques to Avoid

A calque is a phrase translated word-for-word from another language that's grammatically valid Arabic but doesn't read like something a native writer would actually produce. This is the #1 tell that a document was AI-generated or translated rather than composed. This list is not exhaustive — treat it as a pattern to watch for, not a lookup table to run through mechanically.

| Calque (bad) | Source pattern | Better MSA |
|---|---|---|
| أتمنى أن تجدوا هذا الخطاب... | "I hope you find this letter..." | تحية طيبة وبعد، (just start the letter — no need to translate the English opener at all) |
| أود أن أقول أن... | "I would like to say that..." | drop the frame entirely, just state the point |
| في الختام، أود أن أشكركم | "In conclusion, I would like to thank you" | وفي الختام، أتقدم بالشكر... (restructure, don't stack two translated frames) |
| من فضلكم لا تترددوا في التواصل | "Please don't hesitate to contact" | لا تترددوا في التواصل معنا عند الحاجة (drop "من فضلكم" stacked with the imperative — redundant politeness marker from English habit) |
| بخصوص هذا الموضوع، أريد أن أخبركم | "Regarding this matter, I want to tell you" | overloaded frame — go straight to الموضوع: then the point |
| نحن نقدر عملكم الشاق | "We appreciate your hard work" (direct translation) | نقدر جهودكم المبذولة (المجهود الشاق is not idiomatic MSA — جهود مبذولة is) |
| اعتباراً من اليوم فصاعداً | "From today onward" — technically fine but often overused where اعتباراً من [date] alone reads cleaner | trim the "فصاعداً" unless duration emphasis is actually needed |
| كما تعلمون جيداً | "As you well know" — condescending in Arabic in a way it isn't always in English | كما هو معلوم / في إطار متابعتنا لـ... |

## Structural calques (harder to catch, more damaging)

- **English topic-fronting**: English loves "Regarding X, we would like to..." — Arabic formal register more often states the subject line (الموضوع:) separately and starts the body with the situation, not a restated topic phrase.
- **Stacked hedging**: English formal writing stacks softeners ("I was wondering if perhaps you might be able to..."). MSA formal register achieves politeness through the honorific and structure, not through stacked hedges in the sentence itself — a hedge-stacked Arabic sentence reads as anxious, not polite.
- **Short declarative chains**: English business writing favors short sentences. Arabic formal register favors sentences that connect 2-3 related clauses with و / حيث / إذ / كما. A document made of many short standalone sentences reads as translated even if every sentence is grammatically perfect.

## How to self-check while drafting

Ask: "Would a document like this, written originally by an Algerian/Egyptian/Saudi official or professional, actually contain this exact phrase?" If the honest answer is "probably not, but it's grammatically valid," it's a calque — rewrite it.
